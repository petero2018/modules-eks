# Terraform Modules for EKS

Reusable Terraform modules for provisioning EKS infrastructure with consistent standards.

## What This Repository Demonstrates

This repository shows how production-focused EKS infrastructure can be organized into reusable modules with versioning, examples, and generated interface docs. It highlights practical Terraform skills such as module design, composability, secure defaults, and standardized developer workflows.

## Quick Start

1. Review prerequisites and local setup steps in [INSTALLATION.md](INSTALLATION.md).
2. Pick a module from the list below 
3. Reference it from your Terraform stack with a pinned `ref`

```hcl
module "example_bucket" {
  source = "git@github.com:powise/terraform-modules//aws/s3/bucket?ref=aws-s3-bucket-2.0.0"

  bucket_name = "example-bucket"
  tags = {
    team    = "platform"
    service = "example"
    impact  = "high"
  }
}
```


4. Run your standard Terraform flow:
   - `terraform init`
   - `terraform plan`
   - `terraform apply`

## Repository Map

- `README.md`: Entry point with module index and navigation.
- `INSTALLATION.md`: Tooling and setup for local development and contribution.
- `CONTRIBUTING.md`: Workflow, versioning, and module authoring conventions.
- `<service>/<module>/README.md`: Module purpose, usage example, and autogenerated inputs/outputs.
- `current_module_list.sh`: Keeps the module index in this README up to date.
